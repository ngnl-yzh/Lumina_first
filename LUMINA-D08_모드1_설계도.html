01 · 설계 원리

시퀀스로 식별하고, 제때 개입한다

정상 통화에서 “계좌”는 흔하다. 그러나 검찰청 + 대포통장 + 체포영장 + 말하지 마세요 + 안전계좌가 한 통화에 모두 등장할 확률은 사실상 0이다. 보이스피싱은 개별 단어가 아니라 단계의 조합으로 식별된다.

2.1왜 S4가 최고 가중치인가

주의 왜곡 상태는 외부 정보가 유입되면 깨진다. 가족이 “그거 사기야”라고 한 마디만 해도 각성이 풀린다. 사기범은 이를 알고 있고, 그래서 가장 강력하게 차단하는 것이 교차검증이다. S4는 정상 통화에서 나타날 이유가 전혀 없으므로 오탐률이 극히 낮은 고신뢰 신호다.

03 · 실시간 구조

발화 단위로 자르고, 통화 전체를 누적한다

고정 청크로 자르면 키워드가 쪼개진다

“가족에게도 말하지 마세요”(약 2.2초)를 2초에서 자르면 가족에게도 말하지 마 + 세요가 된다. C2 고위험 신호인 “말하지 마세요”가 경계에 걸려 양쪽 어디서도 안 잡힌다. 모드 1은 VAD 발화 단위로 잘라야 한다 — 침묵 0.5초를 문장 끝으로 본다.

모드 2와의 결정적 차이 — 상태 유지

모드 2는 청크마다 독립이다(stateless). 이전 청크가 뭐였든 상관없이 섭동을 계산한다.
모드 1은 다르다. S1이 0:30에, S4가 2:00에 나온다. 통화 전체를 누적해야 단계 커버리지가 성립한다. 최신 발화만 채점하면 커버리지가 영원히 1/N에 머물러 점수가 오르지 않는다. 모드 1은 stateful이다.

# 누적 전사 버퍼 전체로 채점한다 — 최신 발화만 보면 안 된다
def score(buffer_text, db, route):
    act = ROUTE[route]

    # (1) 단계별 매칭 — max(합산 아님)
    hit = {s: max((kw.score for kw in db[s] if match(buffer_text, kw)),
                  default=0.0) for s in act}       ← FIX 빈 시퀀스

    stage_score = sum(hit[s] * W[s] for s in act)

    # (2) 커버리지 — 0보다 큰 단계만 계수
    cov   = sum(1 for s in act if hit[s] > 0) / len(act)  ← FIX 상시최대
    bonus = (cov ** 2) * 1.5

    penalty = count_benign(buffer_text, db) * 0.15

    # (3) 경로별 이론 최대로 정규화
    s = clip((stage_score + bonus) / ROUTE_MAX[route] - penalty, 0, 1)  ← FIX 포화

    # (4) 단독·조합 고위험 하한
    if any_critical(buffer_text, db) or any_pair(hit):
        s = max(s, 0.75)

    # (5) 딥보이스 탐지 결과를 S7 경로 가중치로 반영  (P1)
    if route == 'B' and deepvoice_score > THR:
        s = min(1.0, s + 0.10)

    return s, hit, matched_evidence
